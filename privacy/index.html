Privacy Policy

yt-shorts-pipeline · Last updated 27 November 2026 · About the tool · Terms of Service

yt-shorts-pipeline is a personal automation tool run by Anoshor Paul. It uploads short videos that I create to YouTube channels that I own. It is not offered to the public and has no other users.

YouTube API Services

This tool uses YouTube API Services to upload videos. By using it, you agree to be bound by the YouTube Terms of Service. Information handled through YouTube API Services is also subject to the Google Privacy Policy.

What the tool accesses

It requests one Google permission, https://www.googleapis.com/auth/youtube.upload, which lets it upload videos to the authorizing channel. It does not read, collect or store anyone's personal data, contacts, viewing history, comments, channel statistics or analytics.

What is stored, and for how long

The OAuth refresh token for my own account is kept as an encrypted secret in a private GitHub repository so scheduled uploads can run. The only API response used is the ID of the uploaded video, which is sent back to me as a notification and is not stored anywhere else. Rendered video files are deleted from temporary storage within 2 days. No cookies or tracking are used.

Sharing

No data is sold, shared or transferred to anyone. The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time on the Google security settings page: security.google.com/settings/security/permissions. When access is revoked, the stored refresh token stops working and is deleted from the repository's secrets within 7 days. You can also request deletion of any stored data by writing to the contact address below; it will be deleted within 7 days.
