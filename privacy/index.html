Privacy Policy

yt-shorts-pipeline · Last updated 27 November 2026

yt-shorts-pipeline is a personal automation tool run by Anoshor Paul. It uploads short videos that I create to YouTube channels that I own. It is not offered to the public and has no other users.

What the tool accesses

It requests one Google permission, youtube.upload, which lets it upload videos to my own channels. It does not read, collect or store anyone's personal data, contacts, viewing history, comments or analytics.

What is stored

The OAuth refresh token for my own account is kept as an encrypted secret in a private GitHub repository so scheduled uploads can run. Nothing else from Google APIs is stored. The only API response kept is the ID of the uploaded video, which is sent back to me as a notification.

Sharing

No data is sold, shared or transferred to anyone. The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
